# Tidepool implementation plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. User has authorised autonomous implementation, including design decisions and necessary fixes.

**Goal:** Replace the default Motes experience with an explorable cellular tidepool whose organisms physically move, feed, transfer energy, fragment and grow; preserve the original at `/original.html`.

**Architecture:** A deterministic headless TypeScript model owns cells, elastic bonds, resources and commands. A Canvas 2D renderer, Web Audio engine, and responsive control surface consume the model. Checkpoint history supports rewind, branches and portable JSON experiments.

**Tech stack:** Existing TypeScript, Vite, Vitest and Playwright; native Canvas and Web Audio; no new runtime dependencies.

**Spec:** `docs/superpowers/specs/2026-09-06-motes-alien-tidepool-design.md`.

## Constraints

- The simulation is the artwork. No generated concept image in the runtime world.
- Deterministic fixed simulation step, stable IDs, seeded local behaviour, complete serializable state.
- Energy transfer must not create energy; motion, growth and maintenance have costs.
- Presets are initial conditions. No compulsory plot or chosen survivor.
- Immediate working world; optional audio; keyboard and touch controls; reduced-motion support.
- All changes remain local until reviewed and verified. No external publication required.

## Task 1 — headless physical model

Files: create `src/tidepool/model.ts`, `src/tidepool/world.ts`, `src/tidepool/dynamics.ts`, `tests/tidepool.test.ts`.

Interfaces: `createPool(seed: number, preset?: Preset): Pool`, `stepPool(pool: Pool, options?: { coupling?: boolean; growth?: boolean }): void`, `applyCommand(pool: Pool, command: Command): void`, `clonePool(pool: Pool): Pool`, `colonies(pool: Pool): Colony[]`.

- [ ] Write failing checks for repeatability, finite state, energy transfer accounting, fragmentation, growth costs and useful movement:

```ts
const a = createPool(42); const b = createPool(42);
for (let i = 0; i < 300; i++) { stepPool(a); stepPool(b); }
expect(a).toEqual(b);
```

- [ ] Run `npx vitest run tests/tidepool.test.ts` and confirm missing model fails.
- [ ] Implement cells with polarity, energy, pulse, lineage and three role allocations; elastic bonds with phase-coupled contraction and conservative diffusion; finite nutrient patches; active propulsion, repulsion, damping, current and obstacles; bounded budding and material recycling.
- [ ] Prove the rules with movement and bond-cut comparisons across seeds, recording results through a headless script. Run old and new tests.
- [ ] Commit the coherent model and tests.

## Task 2 — specimen rendering and sound

Interfaces: `PoolRenderer(canvas).draw(pool, view)` and `.toWorld(x,y,view)`; `PoolAudio.enable()`, `.update(pool, selected)`, `.setMuted(muted)`, `.dispose()`.

- [ ] Render actual cell positions and bond topology at full display resolution. Use coherent cellular skins, filament detail, visible pulse transmission, restrained glows, procedural mineral boundaries and resource fields.
- [ ] Provide normal, energy and connection lenses. Selected colonies receive stable emphasis; follow-camera pans without forcing selection.
- [ ] Map bounded colony voices to the model's phase coherence, cell energy, strain and spatial location. Keep audio opt-in and mute reversible.
