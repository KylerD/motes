# Tidepool implementation plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. User has authorised autonomous implementation, including design decisions and necessary fixes.

**Goal:** Replace the default Motes experience with an explorable cellular tidepool whose organisms physically move, feed, transfer energy, fragment and grow; preserve the original at `/original.html`.

**Architecture:** A deterministic headless TypeScript model owns cells, elastic bonds, resources and commands. A Canvas 2D renderer, Web Audio engine, and responsive control surface consume the model. Checkpoint history supports rewind, branches and portable JSON experiments.

**Tech stack:** Existing TypeScript, Vite, Vitest and Playwright; native Canvas and Web Audio; no new runtime dependencies.

**Spec:** `docs/superpowers/specs/2026-09-06-motes-alien-tidepool-design.md`.

## Constraints

- The simulation is the artwork. No generated concept image in the runtime world.
- Deterministic fixed simulation step, stable IDs, seeded local behaviour, complete serializable state.
- Energy transfer must not create energy; motion, growth and maintenance have costs.
- Presets are initial conditions. No compulsory plot or chosen survivor.
- Immediate working world; optional audio; keyboard and touch controls; reduced-motion support.
- All changes remain local until reviewed and verified. No external publication required.

## Delivered scope and verification

The user clarified that the direction should feel like a cosy video game and a lofi page. The implementation follows that direction; the earlier realistic concept is superseded. The default view is quiet, with a deliberate Listen action and deeper tools behind Explore. The model and UI were integrated as one coherent implementation commit rather than separate partial commits.

Fresh verification on 6 September 2026: 53 tests across 8 files passed; TypeScript and production build passed. Desktop 1440×960 and touch 390×844 browser checks passed without page errors. The production-browser check passed cached back navigation, pinch without an accidental intervention, and keyboard intervention. Sampled desktop rendering averaged approximately 2.6 ms. A three-second sound-output sample had peak 0.041 and RMS 0.0086 at 30% volume; this verifies output and headroom, not subjective listening quality.

Ten simulated minutes of seed 2718 in each habitat retained active populations and finite, habitable cell positions. The pond reached its 340-cell cap, crossing ended with 122 cells and scattered beginnings with 290. These are bounded observations, not guarantees of indefinite ecological stability. Independent physics/history and visual reviews were completed; material geometry, import, touch, lifecycle and caption findings were fixed.

The ambitious research outcomes in the original specification are not all claimed. Prepared colonies are explicit, audio is not a bit-exact replay, and this is active-particle physics with external resource supply. README.md documents the shipped behaviour and limitations. No deployment or recurring development loop was created.
