# Motes typefaces

Both fonts are served from this directory, with no runtime request to Google Fonts. The WOFF2 files are the Latin variable-font subsets supplied by Google Fonts on 19 September 2026. Their unmodified SIL Open Font License texts are included alongside them.

- **Nunito Sans**, weights 400–700: interface labels and supporting text. [Google Fonts specimen](https://fonts.google.com/specimen/Nunito+Sans), [WOFF2 source](https://fonts.gstatic.com/s/nunitosans/v19/pe0TMImSLYBIv1o4X1M8ce2xCx3yop4tQpF_MeTm0lfGWVpNn64CL7U8upHZIbMV51Q42ptCp7t1R-s.woff2), [license source](https://github.com/google/fonts/blob/main/ofl/nunitosans/OFL.txt). Local license: `nunito-sans-OFL.txt`.
- **EB Garamond**, weights 400–500: scene captions, panel headings, track and place names. [Google Fonts specimen](https://fonts.google.com/specimen/EB+Garamond), [WOFF2 source](https://fonts.gstatic.com/s/ebgaramond/v33/SlGUmQSNjdsmc35JDF1K5GR1SDk.woff2), [license source](https://github.com/google/fonts/blob/main/ofl/ebgaramond/OFL.txt). Local license: `eb-garamond-OFL.txt`.

The Motes logo uses original path lettering, independent of these fonts. See [brand provenance](../brand/README.md).
