# Motes brand assets

The Motes identity pairs a soft shelter with a warm amber mote and bespoke lowercase lettering. It represents a small, welcoming place to settle into.

An original image-generated concept was created for Motes on 19 September 2026. These production masters were then authored directly as clean SVG geometry, using that concept as visual direction. The lettering is individually drawn path artwork: it has no font dependency, embedded bitmap, or traced third-party logo. No third-party logo was copied.

- `motes-logo.svg`: full transparent lockup, `486 × 114` viewBox (approximately `4.26:1`). Intended header width: `150–200px`.
- `motes-symbol.svg`: standalone transparent shelter, `116 × 114` viewBox.
- `favicon.svg`: shelter on a rounded warm-brown tile, `128 × 128` viewBox.

Colours: ivory `#FFF1DA`, amber `#EAB574`, favicon brown `#302721`. Use the transparent ivory assets over a sufficiently dark surface. Preserve the aspect ratio and the included clear space. SVG paths are the editable production source of truth.
