# Contributing

Thank you for wanting to help. Motes is built in the open, but outside code contributions need a contributor licence agreement (CLA) before they can be merged, so that a future desktop or Steam build stays possible. The CLA process isn't set up yet. Until it is, please open an issue rather than a pull request.

Read [CLAUDE.md](CLAUDE.md), [PRODUCT.md](PRODUCT.md) and [DESIGN.md](DESIGN.md) first; they describe what Motes is and isn't. Run `npm test`, `npm run build` and the browser checks in the README before proposing a change, and `npm run score` for anything that touches rendering, loading or audio.
